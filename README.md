# C++ White-Box Security Assessment

A white-box security assessment of a multithreaded C++ application, compiled and examined in an Ubuntu virtual machine.

The report documents affected code locations, risk levels, and potential fixes for unsafe input handling, buffer overflows, uninitialized variables, data races, file-management issues, and other security weaknesses.

## Files

- `FinalProject (2).cpp` — C++ application examined in the assessment.
- `SecurityAssessmentFinalReport.docx` — Technical report covering scope, findings, risk levels, recommendations, and the assessment process.

## Environment

C++, g++, and an Ubuntu virtual machine.
